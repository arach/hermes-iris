# Iris demo (≤90 seconds)

0–10s: Open Iris dashboard tab. Introduce the redacted sample and 3D Hermes session map.
10–30s: Orbit/zoom; choose a parent agent, then follow a delegation arrow to a child.
30–50s: Scrub the timeline to a failed tool call; show the error highlight and event inspector.
50–65s: Select a code/diff/markdown artifact and show the local preview.
65–78s: Show per-agent tokens, duration, tool calls and errors; distinguish token usage from billed currency.
78–90s: Toggle live mode to show local redacted updates, or explain sample fallback. Close with `/iris` and `hermes iris`.
